# 变更日志

> 本文档记录 workflow_engine 项目的版本变更历史。

---

## v1.0.0 — 初始版本

### 🎉 首次发布

**DAG 执行引擎**
- 基于拓扑排序的 DAG 调度引擎
- BFS 分层算法确定执行顺序
- 同层节点基于 asyncio 并行执行
- 支持 `fail_fast` 和 `continue` 两种错误策略

**7 种节点类型**
- `start` — 开始节点，工作流入口
- `end` — 结束节点，工作流出口
- `llm` — LLM 调用节点，支持 system/user prompt、温度控制、JSON 输出
- `tool` — 工具调用节点，支持参数插值
- `condition` — 条件判断节点，支持 Python 表达式和 LLM 判断
- `code` — 代码执行节点，安全沙箱执行
- `transform` — 数据转换节点

**Web API 服务**
- 基于 FastAPI 的 RESTful API
- 工作流 CRUD 接口（创建、查询、更新、删除）
- 同步执行和流式执行（SSE）接口
- 执行记录查询和统计接口
- 内置 3 个工作流模板
- CORS 跨域支持（环境变量可配置）

**可视化编辑器**
- 内嵌 Web Canvas 编辑器
- 拖拽式节点添加
- 节点连线和属性配置
- 运行状态实时展示
- 暗色主题 UI

**数据库**
- SQLite 持久化存储
- 工作流定义表和执行记录表
- 自动建表和索引优化

**macOS 桌面应用**
- 基于 tkinter 的桌面 GUI
- 暗色主题界面
- 工作流管理和执行功能
- py2app 打包支持

**安全特性**
- CORS 限制为本地访问
- 代码执行节点 AST 级安全沙箱
- 禁止 import、exec、eval、os 等危险操作
- 受限的内置函数白名单
